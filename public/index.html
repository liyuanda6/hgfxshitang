使用提示
  • 「用餐标准」「备注」「应扣除费用」支持行内直接修改，鼠标移开即自动保存。
  • 「本月应就餐天数」由管理员在 班级管理 中设置（需管理密码），此处只读。
  • 计算公式：总费用 = 应就餐天数 × 每日餐费；当月真实费用 = 总费用 − 应扣除费用（不会为负数）。
  • 当月真实费用 ≤ 0 时会标红提示，请核对备注与扣除项。

说明

数据与备份
备份方式：直接复制服务目录下的 data/data.json 文件即可；服务每次写入前会自动生成 data/data.json.bak。 恢复时停止服务 → 用备份文件覆盖 data.json → 重新启动。
关于

班级就餐统计系统 · 纯 Node.js 实现，零第三方依赖，数据存于本地 JSON 文件。

启动命令：node server.js　默认端口：3000（可用环境变量 PORT 修改）

忘记密码：停止服务，删除 data/data.json 后重启即可恢复为默认密码 admin（会清空全部数据，请先备份）。
