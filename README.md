# 班级就餐统计系统

面向学校的学生就餐登记与月度费用统计系统。**纯 Node.js 实现，零第三方依赖**，数据持久化到本地 JSON 文件，可直接部署在普通服务器或内网机器上。

---

## 一、快速开始

### 1. 环境要求

- Node.js **14 及以上**（推荐 18 / 20 / 22）。没有 Node 请先到 https://nodejs.org 下载安装（Windows 下一路"下一步"即可）。
- 无需安装数据库，无需 `npm install`。

### 2. 启动

```bash
cd class-meal-system
node server.js
```

看到如下输出即启动成功：

```
  班级就餐统计系统已启动
  ------------------------------------------
  本机访问：  http://localhost:3000
  数据文件：  ...\class-meal-system\data\data.json
  自动备份：  ...\class-meal-system\data\data.json.bak
  当前月份：  2026-09
  ------------------------------------------
```

### 3. 访问

- 本机浏览器打开：**http://localhost:3000**
- 同局域网内的其他电脑 / 手机：先把本机 IP 查出来（`ipconfig` → IPv4 地址，例如 `192.168.1.23`），然后访问 **http://192.168.1.23:3000**

> **注意**：若访问不了，多半是防火墙拦截。以 Windows 为例，需在"Windows Defender 防火墙 → 入站规则"中放行 3000 端口（TCP）。

### 4. 修改端口

```bash
# Windows (PowerShell)
$env:PORT=8080; node server.js

# Windows (CMD)
set PORT=8080 && node server.js

# Linux / macOS
PORT=8080 node server.js
```

### 5. 后台常驻运行（可选）

```bash
# Linux / macOS：用 systemd 或 nohup
nohup node server.js > server.log 2>&1 &

# Windows：可用 nssm 把 node server.js 注册为系统服务
nssm install ClassMeal "C:\Program Files\nodejs\node.exe" "C:\path\to\class-meal-system\server.js"
```

首次访问默认管理密码为 **`admin`**，请登录后立即到「系统设置」修改。

## 三、功能说明

### 导航

| 页面 | 用途 |
|---|---|
| **就餐登记** | 核心页面。按「班级 + 月份」一屏展示全班学生，行内修改用餐标准 / 备注 / 应扣除费用，费用自动计算，底部有合计行 |
| **班级管理** | 新增 / 改名 / 删除班级；**批量或单班设置本月应就餐天数**（需管理密码） |
| **学生管理** | 单个新增 / 编辑 / 删除；**批量导入**（粘贴文本或选 .csv/.txt 文件） |
| **统计报表** | 全校汇总、各用餐标准人数、按班级明细表，可导出全校 CSV |
| **系统设置** | 餐费标准、修改管理密码、数据备份 |

### 费用计算规则

| 用餐标准 | 每日餐费 |
|---|---|
| 早餐 + 中餐 | 早餐价 + 午餐价（默认 6 + 11 = **17 元**） |
| 仅早餐 | 早餐价（默认 **6 元**） |
| 仅中餐 | 午餐价（默认 **11 元**） |

```
总费用      = 本月应就餐天数 × 该生每日餐费
应扣除费用  = 手工填写（请假 / 全天未在校就餐 / 其他原因）
当月真实费用 = max(总费用 − 应扣除费用, 0)      ← 不会出现负数
```

示例（应就餐 18 天，默认餐价）：早餐+中餐 306 元、仅早餐 108 元、仅中餐 198 元。
再减去应扣除费用即为当月真实费用，若为负则记 0 并**标红提示**。

### 需要管理密码的操作

- 批量 / 单班设置应就餐天数
- 修改餐费标准
- 修改管理密码
- 删除班级（需二次确认 + 密码）

密码使用 **SHA-256 加盐哈希**存储，不明文保存，也不保存在浏览器端。

### 学生导入格式

每行一名学生：`姓名，身份证号`。分隔符支持 **逗号、中文逗号、顿号、分号、空格、制表符**：

```
张三，110101201501010019
李四 110101201501020026
王五	110101201501030033
```

导入时会自动：清洗首尾空格 → 字母统一大写 → **18 位格式与第 18 位校验位校验** → **按身份证号去重** → 默认用餐标准设为「早餐+中餐」。
支持 UTF-8 与 GBK 两种编码的 .csv 文件（Excel 另存的 CSV 通常可用）。

### 月份管理

- 顶部可自由切换月份（含快捷月份标签）。
- 天数与登记数据均按「班级 + 月份」独立保存，**切换新月份从零开始，历史月份完整保留、可随时回看**。

## 四、数据备份与恢复

**备份**：直接复制 `data/data.json` 文件即可（或在系统设置页点「下载数据备份」）。
服务每次写入前还会自动生成上一版本的 `data/data.json.bak`。

**恢复**：

1. 停止服务（Ctrl+C）；
2. 用备份文件覆盖 `data/data.json`；
3. 重新启动 `node server.js`。

> 建议每学期末把 `data` 整个目录复制到 U 盘或网盘归档一次。

## 五、忘记管理密码

**方法一（保留数据，推荐）**：停止服务后，在 `class-meal-system` 目录下执行下面这行命令，把管理密码重置为 `admin`，然后重启服务、到系统设置页改成自己的密码。

```bash
node -e "const f='data/data.json',fs=require('fs'),c=require('crypto');const s=fs.readFileSync(f,'utf8');const d=JSON.parse(s);d.settings.salt='0'.repeat(32);d.settings.passwordHash=c.createHash('sha256').update(d.settings.salt+'::admin').digest('hex');fs.writeFileSync(f,JSON.stringify(d,null,2),'utf8');console.log('密码已重置为 admin')"
```

**方法二（会清空数据）**：停止服务 → 删除 `data/data.json` → 重新启动，密码重置为默认的 `admin`。

> ⚠️ 方法二会清空全部数据，请先备份 `data` 目录。

## 六、验收自测

项目附带一个自测脚本，覆盖需求中的全部验收要点：

```bash
# 先启动服务
node server.js

# 另开一个终端（会往 data.json 写入测试数据，建议在测试环境执行）
node test-smoke.js
```

覆盖项包括：批量设置天数的默认全选 / 部分勾选 / 密码校验、错误密码拒绝；导入学生的格式解析、身份证校验、去重、默认标准；18 天费用示例（306 / 108 / 198）、扣除后不为负、实时重算；CSV 字段齐全、含合计行、UTF-8 BOM；历史月份切换；数据持久化与密码哈希存储。

## 七、常见问题

**Q：多人同时用会不会冲突？**
A：系统适用于一个统计员 / 各班主任先后录入的场景。同一条记录以最后保存的为准；若并发量很大，建议由统计员统一录入。

**Q：数据量大时慢不慢？**
A：全校 2000 名学生、12 个月记录量级下毫秒级响应。数据量特别大时可定期在系统设置页「清空当前月份登记数据」归档历史月份。

**Q：可以放到公网上吗？**
A：系统本身只做了管理密码保护，未做 HTTPS 与防暴力破解。**建议仅在校园内网使用**；若必须公网访问，请在前置 Nginx 上配置 HTTPS 并限制来源 IP。
